Inspora

Connect to Inspora

Find design references in your AI agent. This trial is available to approved Inspora team accounts.

Install

Claude Code and Codex install Inspora as a plugin: one install adds the Inspora connection and its two skills, inspora-discovery and inspora-design-direction. The plugin holds no credentials. You still sign in with an approved Inspora team account.

Claude Code

1. Install the plugin

claude plugin marketplace add Aymen-Ben-Salem/inspora#preview/archive-updates
claude plugin install inspora@inspora-team

Inside a Claude Code session, use /plugin marketplace add … and /plugin install … instead. If the GitHub download fails on a machine without an SSH key, set CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1 and run the commands again.

2. Sign in

Start Claude Code, or run /reload-plugins in an open session. Run /mcp, select plugin:inspora:inspora, choose Authenticate, then sign in to Inspora and choose Allow connection.

3. Remove an earlier manual setup

If you set Inspora up by hand before, remove that setup. Otherwise the old connection is used instead of the plugin's and the skills appear twice.

claude mcp remove inspora -s user
npx skills remove inspora-discovery inspora-design-direction -g -a claude-code -y

Either command can report that nothing was found; that is fine. claude mcp list should then show only plugin:inspora:inspora.

Codex

1. Install the plugin

codex plugin marketplace add Aymen-Ben-Salem/inspora --ref preview/archive-updates
codex plugin add inspora@inspora-team

In the Codex app or an interactive session, you can also open /plugins after adding the marketplace and install Inspora from the Inspora team list.

2. Remove an earlier manual setup

An earlier manual inspora entry takes the place of the plugin's connection, so remove it and the separately installed skills:

codex mcp remove inspora
npx skills remove inspora-discovery inspora-design-direction -g -a codex -y

Either command can report that nothing was found; that is fine.

3. Sign in

codex mcp list

The inspora row should show https://mcp.inspora.design/mcp. If its Auth column says Not logged in, run codex mcp login inspora, sign in to Inspora and choose Allow connection. Then start a new Codex session.

Another agent

Add https://mcp.inspora.design/mcp in your agent's MCP settings using Streamable HTTP and OAuth, then sign in to Inspora and allow the connection. Install the two skills with the installer ID of your client from the supported agents list:

npx skills add https://mcp.inspora.design -g --agent <installer-id> -y

The skills installer needs Node.js 22.20 or newer. On Windows PowerShell, if npx is blocked by the script execution policy, use npx.cmd or Command Prompt. Client support for MCP, OAuth and skills varies.

Check it is ready

In a new conversation, ask your agent: Call Inspora catalog_status. Inspora is ready when it reports a search_revision, work counts and catalog_state ready. If it says updating, retry after the seconds it gives.

Try it

Ask your agent:

Use Inspora to find ten dark website hero sections with bold typography. Include links.

Expect relevant references with creator credits and Inspora links, or an explanation if fewer strong matches are available. Search is the default. Ask for help choosing a visual direction, comparing references or developing a brief when you want guidance. The agent can select the skills from that request automatically.

Need help?
  • Command not found: update Claude Code or Codex to its current version; the plugin commands need a recent release. For npx, install the current Node.js LTS release and reopen the terminal.
  • An older Inspora is used instead: a manual or project inspora entry takes precedence over the plugin. List entries with claude mcp list or codex mcp list and remove the extra one (for Claude Code, claude mcp remove inspora --scope project or --scope local as well).
  • Skills listed twice: remove the separately installed copies with the npx skills remove command for your client above.
  • Sign-in required: Claude Code: /mcp, then Authenticate. Codex: codex mcp login inspora.
  • Access denied: use an approved Inspora team account or contact the team for access.
  • Skills or tools missing: start a new conversation; restart your agent or extension if they are still missing. Check the plugin is enabled with claude plugin list or codex plugin list.
  • Service unavailable: retry later and share the error with the team, excluding credentials and callback URLs.
Catalog and search improvements arrive automatically. To update the plugin's skills, run claude plugin marketplace update inspora-team then claude plugin update inspora@inspora-team, or codex plugin marketplace upgrade inspora-team then codex plugin add inspora@inspora-team. Other agents rerun their skill-install command. Uploaded reference-image search is deferred to the future backlog. Your AI agent's normal model usage applies.
