Inspora

Connect to Inspora

Find design references in your AI agent. MCP access is currently available to approved Inspora team accounts.

Ask your agent to set it up

Copy this prompt into your agent.

Set up Inspora for me.

1. Add https://mcp.inspora.design/mcp as a Streamable HTTP MCP server and sign me in through OAuth if needed.
2. Install the skills from https://mcp.inspora.design for my current agent using npx skills add.
3. Check catalog_status, then find six examples for a design idea I give you.

Complete the browser sign-in and choose Allow connection.

Install the skills yourself

npx skills add https://mcp.inspora.design -g

Select the Inspora skills and the agent or agents you use. The installer uses Node.js. The skills help you refine searches, compare references and develop a design direction. Start a fresh agent session after installation.

Install for every supported agent 
npx skills add https://mcp.inspora.design -g --all

This creates an installation for every agent the installer supports, including agents you may not have installed.

Connect the MCP manually

Use your agent’s MCP settings to add this server URL and sign in.

https://mcp.inspora.design/mcp

For Codex, run the following command. If sign-in is still needed, run codex mcp login inspora.

codex mcp add inspora --url https://mcp.inspora.design/mcp

For Claude Code, run these commands.

claude mcp add --transport http --scope user inspora https://mcp.inspora.design/mcp
claude mcp login inspora

Try it

Ask “Use Inspora to find playful navigation designs.” Ask for more, refine the direction or compare selected references.

Catalog updates arrive automatically. Uploaded reference-image search is planned for Phase 2. Your AI agent’s normal model usage applies.
