# Domain docs

This repo uses a single context: root `CONTEXT.md` and `docs/adr/`.

## Before exploring

Read root `CONTEXT.md` and ADRs in `docs/adr/` relevant to the area being explored. If they do not exist, proceed silently; do not propose creating them upfront. The domain-modeling skill creates them when domain terms or decisions are resolved.

## Vocabulary and decisions

Use the glossary terms from `CONTEXT.md` in issue titles, proposals, hypotheses, and tests. Reconsider unfamiliar terms or note genuine glossary gaps for domain-modeling.

Explicitly identify contradictions with existing ADRs and explain why a decision should be reconsidered.
