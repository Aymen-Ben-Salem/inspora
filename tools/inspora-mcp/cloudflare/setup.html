Ask your agent to set it up

Copy this prompt into the agent you use, then complete the browser sign-in.

Set up Inspora for me.

1. Connect https://mcp.inspora.design/mcp using Streamable HTTP and OAuth. Reuse an existing correct connection and sign me in if needed.
2. Install inspora-discovery and inspora-design-direction from https://mcp.inspora.design with npx skills add, using -g -y and an explicit --agent for my current client (codex, claude-code, or its supported installer ID).
3. Verify both installed skills are available to this agent, then call catalog_status through Inspora. Say "Inspora is ready" only when those checks succeed. If a check fails, explain the specific next step.

The skills installer needs Node.js 22.20 or newer. If the agent needs a new conversation to load its tools or skills, open one and ask it to finish the checks.

Set up manually

Choose your agent. You will connect Inspora, install its two skills, then check they are ready.

Codex

1. Connect Inspora

Add this URL in Codex's MCP settings and sign in:

https://mcp.inspora.design/mcp

Or use the installed Codex CLI:

codex mcp add inspora --url https://mcp.inspora.design/mcp

Choose Allow connection in your browser. If sign-in is still needed, run codex mcp login inspora. If the correct URL is already connected, continue.

2. Install the skills

npx skills add https://mcp.inspora.design -g --agent codex -y

3. Check the installation

npx skills list -g --agent codex

Look for inspora-discovery and inspora-design-direction. In Codex, confirm both are available in the skills selector and Inspora is connected in MCP settings. Start a fresh conversation if needed, then try a search below.

Claude Code

1. Connect Inspora

claude mcp add --transport http --scope user inspora https://mcp.inspora.design/mcp

If the correct URL is already connected, continue. Otherwise run claude mcp login inspora, sign in and choose Allow connection. You can also authenticate through /mcp in a Claude Code session.

2. Install the skills

npx skills add https://mcp.inspora.design -g --agent claude-code -y

3. Check the installation

npx skills list -g --agent claude-code

Look for inspora-discovery and inspora-design-direction. Start a fresh Claude Code conversation if needed and confirm Inspora is connected through /mcp. Then try a search below.

Another agent or several agents

Add https://mcp.inspora.design/mcp in your agent's MCP settings using Streamable HTTP and OAuth. Sign in to Inspora and allow the connection.

In either skills command above, replace the value after --agent with your client's supported installer ID. For several agents, name them explicitly, such as --agent codex claude-code.

Check both skills are available and the MCP connection succeeds in that client. Client support for MCP, OAuth and skills varies.

Try it

Ask your agent:

Use Inspora to find ten dark website hero sections with bold typography. Include links.

Expect relevant references with creator credits and Inspora links, or an explanation if fewer strong matches are available. Search is the default. Ask for help choosing a visual direction, comparing references or developing a brief when you want guidance. The agent can select the skills from that request automatically.

Need help?
  • Command not found: use your client's MCP settings if its CLI is unavailable. For npx, install the current Node.js LTS release and reopen the terminal.
  • Inspora already exists: check that its saved URL is https://mcp.inspora.design/mcp and use that connection.
  • Sign-in required: authenticate Inspora in your client's MCP settings.
  • Access denied: use an approved Inspora team account or contact the team for access.
  • Skills or tools missing: start a fresh conversation; restart your agent or extension if still missing, then check again.
  • Earlier PromptScript warning: check whether both skills installed for your agent. If needed, rerun its explicit command above.
  • Service unavailable: retry later and share the error with the team, excluding credentials and callback URLs.
Catalog and search improvements arrive automatically. To update the local skills, rerun your agent's skill-install command. Uploaded reference-image search is planned for Phase 2. Your AI agent's normal model usage applies.
